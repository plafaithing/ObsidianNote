# Lessons — 防重复犯错

> 用户每次纠正后立即记录模式 + 给自己写规则。会话开始时复习。

## L001 · 出题不重复；不懂出变种题

**触发**：2026-07-27，harness-engineering 主题。用户反馈"后面出题不要出现重复的题；对部分问题始终不懂时，多出类似的变种题来巩固"。

**失误模式**：L05 随堂题 4 道里，有 3 道与紧接其后的 quiz-01 模块测验同角度重复（CC prompt 515 段、Executing actions with care→安全层、售前改行为→CLAUDE.md）。随堂题和模块测验本应错开，但只在"模块测验×期中"层面防重，漏了"随堂×模块测验"这层。

**根因**：CLAUDE.md 已写"阶段测验与期中/其他测验错开考察角度"，但执行时把"随堂题"当独立层，没纳入去重范围。实际上随堂题、模块测验、期中、期末**四层所有题目共享一个去重池**。

**规则（给自己）**：
1. **全局去重**：出任何新题前，先扫已有题（随堂 + 各 quiz + 期中期末），同概念同角度的不重复出。同概念可以多次出现，但**必须换场景/换角度/换考法**（如随堂考"识别层"、模块考"在该层做决策"、期中考"跨层排错"）。
2. **维护题库索引**：每出一批题，在 `learning/<主题>/lessons/` 下维护一份题库清单（题干要点 + 考察点 + 出处），便于去重查重。
3. **变种题策略**：用户对某题"始终不懂"时，不要原题重出——出**同概念不同场景的变种**（换数据、换角色、换提问方向），从多角度巩固，直到用户能独立答对。
4. **错开维度清单**（同概念可沿这些维度错开）：识别类 / 机制原理类 / 决策选型类 / 排错诊断类 / 场景应用类。

**迁移**：适用于所有教学主题的出题环节，不限 harness-engineering。
