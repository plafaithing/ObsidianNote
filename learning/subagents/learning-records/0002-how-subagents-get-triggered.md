# 0002 · 里程碑：理解子 agent 的触发机制

> 学习记录 · 2026-06-26

## 里程碑
用户理解了：调用子 agent **不需要特定 prompt 触发**，模型能自主判断；但是否倾向于派受五方面影响（模型倾向 / 系统提示 / skill / CLAUDE.md / 用户直接要求）。结论：不写也能派，写了更可靠一致——不是"必须写明否则无法拆"。

## 同期澄清
- **只读 agent**（如 `Explore`）：不能写文件，结果只能返回主会话。
- **可写 agent**（如 `general-purpose`）：有 Write 工具，可在 prompt 里要求"写入 X 文件"直接落盘。

## 影响
- 用户可通过 CLAUDE.md 写偏好（如"读 PDF / 大项目分析优先派子 agent"）让模型更积极派
- 用户也可直接要求派——最可靠的触发方式
