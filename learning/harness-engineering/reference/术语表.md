# 术语表 — Harness Engineering

> 教学统一用语。新概念先在此登记，课程中一律沿用此处释义。
> 基础薄弱友好：每条先一句大白话，再补技术要点。

## 核心概念

- **harness（线束 / 脚手架）**：包裹基础模型的那层工程，把"会聊天的模型"变成"能干活的 agent"。包含系统提示词、工具、循环、上下文管理、权限等。Claude Code 就是一个完整 harness。
- **基础模型 / 裸模型**：未经 harness 包裹的 LLM，只能一问一答、无状态、不能动手。
- **augmented LLM（增强 LLM）**：Anthropic 的基础构建块 = 模型 + 检索 + 工具 + 记忆。harness 的起点。
- **agentic system（agent 系统）**：Anthropic 对所有"LLM + 工具"系统的统称，下分 workflow 和 agent 两类。
- **workflow（工作流）**：LLM 和工具通过**预定义代码路径**编排——步数和走向由代码写死。
- **agent（智能体）**：LLM **动态指挥自己的流程和工具使用**，自主决定怎么完成任务。
- **agentic loop（agent 循环）**：agent 的心跳。`while: 模型决策 → 调工具 → 把结果喂回 → 再决策`，直到任务完成或触发停止条件。

## 工具相关

- **tool use（工具调用）**：模型在响应里返回一个"工具调用块"，由 harness 执行后把结果喂回模型。
- **tool / tool definition（工具 / 工具定义）**：模型能调用的能力，由 schema（参数）+ 描述定义。Claude Code 内置 Read/Write/Edit/Bash/Glob/Grep 等。
- **tool loop（工具循环）**：见 agentic loop。Client SDK 要你自己写这个循环；Agent SDK 由 Claude 自主处理。
- **ACI（agent-computer interface）**：agent 与工具的接口。Anthropic 强调 ACI 应像 HCI（人机接口）一样被认真设计——工具描述要给模型足够信息、防呆。
- **MCP（Model Context Protocol）**：连接外部系统（数据库、浏览器、API）的协议，让 harness 接入更多工具。

## 上下文相关

- **context window（上下文窗口）**：模型一次能"看见"的 token 上限。超了就要压缩或裁剪。
- **context management / context engineering（上下文管理 / 上下文工程）**：决定什么信息进上下文、什么被压缩/丢弃、何时注入记忆。
- **memory（记忆）**：跨轮/跨会话持久化的上下文。Claude Code 里 `CLAUDE.md` 是项目级记忆。
- **session（会话）**：一段连续的 agent 交互，含历史与状态。可 resume（续） / fork（分叉）。

## 控制相关

- **permission（权限）**：控制 agent 能用哪些工具、对什么资源操作。allow / deny / ask（批准）。
- **hooks**：在 agent 生命周期关键点（PreToolUse / PostToolUse / Stop / SessionStart…）运行的自定义代码，可拦截/验证/转换/记录行为。
- **subagent（子 agent）**：主 agent 派出去处理聚焦子任务的专门 agent，有独立上下文，跑完返回结果。
- **guardrails（护栏）**：约束 agent 行为、防止越界的机制（权限、hooks、停止条件等）。
- **ground truth（地面真相）**：agent 每步从环境（工具结果、代码执行）获取的真实反馈，用来评估进展。

## 编排模式（Anthropic 五种）

- **prompt chaining（提示链）**：任务拆成顺序步骤，每步处理上一步输出，可加 gate 检查。用延迟换准确度。
- **routing（路由）**：先分类输入，再导向专门处理。关注点分离。
- **parallelization（并行）**：sectioning（独立子任务并行）/ voting（同任务多次取多样输出）。
- **orchestrator-workers（编排者-工人）**：中央 LLM 动态拆解任务、委派 worker、综合结果。子任务**非预定义**，由 orchestrator 按输入决定。
- **evaluator-optimizer（评估器-优化器）**：一个 LLM 生成、另一个评估反馈、循环改进。

## 工具与产品名

- **Claude Code**：终端里的 agentic 编码工具，一个完整 harness（闭源 CLI，但配置面可观察/可定制）。
- **Claude Agent SDK**：Claude Code 的开源内核（Python/TS），"the same tools, agent loop, and context management that power Claude Code"。读它 ≈ 读 Claude Code 实现。
- **Client SDK**：底层 Anthropic SDK，直接调 API，工具循环自己写。
- **Managed Agents**：Anthropic 托管的 agent REST API，agent 和 sandbox 都在 Anthropic 跑。
