术数 · 共享基础 第 3 / 4 节

八卦与六十四卦 · 万物类象

四门术数共用的卦象符号系统
🎯 本课小胜利：① 能凭卦象认出八个卦（乾兑离震巽坎艮坤）
② 能说出每卦的自然、身体、动物、家庭类象
③ 能用「上卦 + 下卦」拼出一个六十四卦（如地天泰）

一、为什么学八卦

八卦是四门术数的「卦象骨架」。上一节干支是字母表，这一节八卦就是「词根」：

  • 六爻：一个六爻卦 = 上下两个八卦相叠，装卦时要分清上卦下卦
  • 梅花易数：用先天八卦数起卦，断卦时直读八卦万物类象
  • 奇门遁甲：九宫里排的就是后天八卦方位
  • 大六壬：天将与八卦方位对应，断象时也取八卦类象

所以八卦的形状、五行、类象是后面所有断卦的视觉与语义基础。

二、八卦的卦象与口诀

每个卦由三爻组成（叫「经卦」）。爻从下往上读：初爻 → 二爻 → 三爻。实线 ⚊ 为阳爻，断线 ⚋ 为阴爻。

八卦顺序（先天序）：乾 兑 离 震 巽 坎 艮 坤。记忆口诀「八卦取象歌」：

口诀看形：乾三连（三实线）、坤六断（三断成六段）；震仰盂（像口朝上的碗，底实口空）、艮覆碗（倒扣的碗，上实下空）；离中虚（中间断）、坎中满（中间实）；兑上缺（顶上断一口）、巽下断（底下断）。

家庭角色（出自《说卦传》）

把八卦看成一家八口：乾父坤母，下面三儿三女。「长、中、少」由从下往上第几个阳爻/阴爻决定。

卦角色爻象（自下而上）怎么来的
乾 ☰父阳阳阳纯阳
坤 ☷母阴阴阴纯阴
震 ☳长男阳阴阴初爻为阳 → 长男
坎 ☵中男阴阳阴二爻为阳 → 中男
艮 ☶少男阴阴阳三爻为阳 → 少男
巽 ☴长女阴阳阳初爻为阴 → 长女
离 ☲中女阳阴阳二爻为阴 → 中女
兑 ☱少女阳阳阴三爻为阴 → 少女
规律：阳卦（震坎艮）是「一阳两阴」，阴卦（巽离兑）是「一阴两阳」。谁在下谁是长——初爻定长幼，因为事物从下往上长。这条规律在断卦里也用：占长子看震、占中男看坎。

四、八卦万物类象（核心）

万物类象 = 把世间万物归到八个卦上。这是梅花直读、六爻取象、奇门断意的共同基础。下表出自《周易·说卦传》及后世易学扩充：

卦自然方位(后)季节五行 家庭身体动物特性
乾 ☰天西北秋冬间金父首(头)马刚健·尊贵
兑 ☱泽西秋金少女口羊喜悦·口舌
离 ☲火南夏火中女目雉光明·依附
震 ☳雷东春木长男足龙震动·奋起
巽 ☴风/木东南春夏间木长女股(腿)鸡顺入·渗透
坎 ☵水北冬水中男耳豕(猪)险陷·曲折
艮 ☶山东北冬春间土少男手狗静止·阻止
坤 ☷地西南夏秋间土母腹牛柔顺·承载
📌 速记三条线：① 身体「乾首坤腹震足巽股坎耳离目艮手兑口」② 动物「乾马坤牛震龙巽鸡坎豕离雉艮狗兑羊」③ 家庭「乾父坤母·震长坎中艮少(男)·巽长离中兑少(女)」。这三条是《说卦传》原文，最常考、最常用。
类象不止上面这些——乾还可为君、为玉、为金；坤为众、为布、为釜；坎为盗、为病、为酒；离为日、为电、为甲胄……随课程推进会随用随补，不必一次硬背。梅花断卦时讲究「见什么取什么象」，先用熟这张主表。

六、六十四卦怎么来的

把两个经卦（三爻卦）上下叠起来，就成了六爻卦，叫「别卦」。8 个经卦两两组合 = 8 × 8 = 64 卦。

  • 上卦（外卦）：上面三爻，代表外环境、对方
  • 下卦（内卦）：下面三爻，代表内环境、自己

命名格式：「上卦象 + 下卦象 + 卦名」。举几个最经典的：

卦名读法上卦下卦卦象含义
泰地天泰坤☷(地)乾☰(天)
地气下降、天气上升，天地交，通达
否天地否乾☰(天)坤☷(地)
天气上行、地气下行，不交，闭塞
既济水火既济坎☵(水)离☲(火)
水在火上（如锅烧水），事成
未济火水未济离☲(火)坎☵(水)
火在水上，不交，事未成
🔑 泰 vs 否是理解六十四卦的钥匙：不是「乾就好、坤就坏」，而是看上下卦气是否相交。泰卦地在上天在下，气相向而行则交；否卦天在上地在下，气相背而行则不交。六爻里看动爻生克、梅花里看体用，底层都是这个「交不交」的道理。
六十四卦各有固定卦名（出自《周易》），不必现在全背。六爻装卦时会自动给出本卦和变卦的名称，重点是会拆「上卦 + 下卦」。

八、小结与预告

✅ 本课你掌握了：

  • 八个卦的卦象与口诀（乾三连、坤六断、震仰盂、艮覆碗、离中虚、坎中满、兑上缺、巽下断）
  • 八卦的五行（乾兑金、震巽木、坎水、离火、坤艮土）与家庭（长中少由初/二/三爻定）
  • 万物类象主表：自然、方位、身体、动物、特性——梅花直读与六爻取象的基础
  • 先天为体后天为用：梅花用先天数起卦，方位旺衰看后天八卦
  • 六十四卦 = 上下两个八卦相叠，命名「上象+下象+卦名」（如地天泰）
下节预告 第 4 课：干支历法（年月日时、节气、月建日辰、旬空）
这是共享基础最后一节。学会把一个具体时间转成「年柱、月柱、日柱、时柱」四柱，理解节气如何定月建、如何查旬空——这是六爻定日辰、六壬起课、奇门定局的共同前置技能。学完就能进入第二阶段：六爻。
