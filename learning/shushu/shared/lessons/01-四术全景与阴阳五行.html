一、术数四门全景

你要学的四门术数，底层共通：都建立在「共时性」原理上——你起卦 / 起盘的瞬间，宇宙的信息就映射在卦盘里。它们共享同一套符号（阴阳五行、天干地支、八卦），区别在起卦方式与断法模型。

术数核心模型难度特色
六爻
（纳甲法）		干支 + 六亲 + 世应 + 日辰月建中实战性强，体系成熟
梅花易数体用生克 + 万物类象轻起卦灵活，重意象
大六壬四课三传 + 十二天将 + 神煞重占人事最精，「来人不用问」
奇门遁甲九宫 + 八门 + 九星 + 八神 + 三奇六仪重择时择方谋事，「帝王之学」

四门各自的流程一句话：

六爻 周易占卜

摇三硬币得六爻 → 装干支六亲 → 看日辰月建断吉凶

梅花易数 周易占卜

以时间 / 数字 / 外应起卦 → 定体用 → 看体用生克断吉凶

大六壬 三式

以月将加占时排天地盘 → 推四课三传 → 看天将课体断吉凶

奇门遁甲 三式

以节气定局排盘 → 布八门九星八神三奇六仪 → 看格局主客断吉凶

三、阴阳

万物分阴阳，这是四门术数最底层的二分法。

阳
动 · 热 · 明 · 刚 · 奇数
男 · 太阳 · 白天
阴
静 · 冷 · 暗 · 柔 · 偶数
女 · 月亮 · 黑夜

阴阳在四门里的体现（六爻为例，其他门同理）：

  • 阳爻 ⚊（一条实线）/ 阴爻 ⚋（断开）
  • 硬币：背为阳（数 3），字为阴（数 2）
  • 摇卦得数：7、9 为阳（奇），6、8 为阴（偶）
    其中 7 少阳、8 少阴为静爻（不变）；9 老阳、6 老阴为动爻（物极必反，将变）

四、五行

金、木、水、火、土是五种能量状态，不是五种物质。四门断卦几乎全靠五行之间的生克关系。

五行方位季节颜色特性
木东春青生长、升发
火南夏赤炎热、向上
土中四季末黄承载、化育
金西秋白肃杀、收敛
水北冬黑滋润、向下

五、五行相生（谁养谁）

相生 = 互相滋养、促成。

木→生→ 火→生→ 土→生→ 金→生→ 水→生→ 木

🧠 记忆：烧木生火 → 火尽成灰（土）→ 土中藏金 → 金熔化成水 → 水润木长。

六、五行相克（谁制谁）

相克 = 互相制约、克制。

木→克→ 土→克→ 水→克→ 火→克→ 金→克→ 木

🧠 记忆：树根破土 → 土筑堤挡水 → 水灭火 → 火熔金 → 金斧砍木。

注意：相生与相克是两套独立循环，别混。木既生火又克土；火既生土又克金。
