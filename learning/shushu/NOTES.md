# 术数学习 — 备忘

## 用户偏好
- 零基础起步，共享基础先行
- 重实战：目标是能断准真实事项，理论够用即可
- 主用场：自己占卜为主，兼给别人看以辅证
- 共性知识点提前讲明，避免重复
- 保留专业术语文档（reference/）方便后期查阅
- 课程格式：HTML；归档：md 放 archive/
- 语言：中文

## 教学备忘
- 每节给一个可练小技能 + 小胜利，落在最近发展区
- 共享基础课要明确标注「哪些术数会用到」，让用户知道为什么学
- 装盘 / 装卦是新手最容易卡的一步（六爻装卦、六壬排课传、奇门排盘），要拆细、多练、给口诀
- 断卦核心都是「取用神 / 类神 + 旺衰 + 生克」，这个思维在共享基础就要埋下
- 四门学完一门后，与已学门做对照（六爻 vs 梅花起卦差异，六爻 vs 六壬干支六亲共通）
- 网络常见错误：少阳 / 少阴搞反——以经典为准（7 阳 8 阴），遇到要纠正

## 术语文档维护
- `reference/glossary.md`：按模块分类的术语表，每节课新出现的术语及时补入
- `reference/cheatsheet.md`：速查表（五行生克、地支冲合、八卦类象、六亲、天将、八门九星等），随进度扩充
