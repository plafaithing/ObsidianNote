# 术数学习主题 Mission

> 学什么：中国传统术数四大占卜体系 — 六爻、梅花易数、大六壬、奇门遁甲
> 为什么学：自己占卜为主，兼给别人看以辅证学习，重实战

## Why（为什么学）
- 主用场「自己占」：遇到跳槽、投资、感情、失物等具体事项，用术数辅助判断吉凶成败与时机。
- 兼「给别人看」：用真实占验检验和巩固所学。
- 重实战：理论够用就行，核心目标是能断准真实事项。
- 四门一块学：共享阴阳五行 / 干支 / 八卦基础，分门掌握各自起卦与断法，互相印证。

## 四门定位
| 术数 | 体系 | 核心模型 | 难度 | 特色 |
|------|------|----------|------|------|
| 六爻（纳甲法）| 周易占卜 | 干支 + 六亲 + 世应 + 日辰月建 | 中 | 实战性强，体系成熟 |
| 梅花易数 | 周易占卜 | 体用生克 + 万物类象 | 轻 | 起卦灵活，重意象 |
| 大六壬 | 三式 | 四课三传 + 十二天将 + 神煞 | 重 | 占人事最精，「来人不用问」|
| 奇门遁甲 | 三式 | 九宫 + 八门 + 九星 + 八神 + 三奇六仪 | 重 | 择时择方谋事，「帝王之学」|

> 四门底层共通：都建立在「共时性」原理上——起卦/起盘的瞬间，宇宙信息映射在卦盘里。共享同一套符号（阴阳五行、干支、八卦），区别在起卦方式与断法模型。

## 成功标准
1. **共享基础**：掌握阴阳五行、天干地支、八卦类象、干支历法（四门通用）
2. **每门能起盘**：六爻能装卦盘；梅花能起卦定体用；六壬能排四课三传；奇门能排完整局盘
3. **每门能断卦**：针对具体问题断出吉凶成败方向 + 应期
4. **实战占验**：每门完成 ≥1 次真实事项占验并复盘（六爻 ≥3 次，作为主力）

## 约束
- 基线：零基础，共享基础先行
- 路径：共享基础 → 六爻 → 梅花 → 六壬 → 奇门（由轻到重，六爻先达成实战）
- 重实战，轻考据：理论服务于断卦，不深入学术争议
- 共性知识点在共享基础模块提前讲明，分门课程引用不再重复

## 范围外
- 不学八字命理（四柱）、风水、面相、手相等其他术数
- 不做古籍考据和流派之争
- 不涉及「五弊三缺」等迷信话题

## 北极星目标
**四门各能独立占验真实事项**：从一件真实困惑出发，能用至少两种术数分别起盘断卦，对照印证，事后复盘验证。

## 学习路径与课程序列（约 40 节）

### 第一阶段 · 共享基础（shared/，4 节）
1. 四术全景 + 阴阳五行生克 ✅
2. 天干地支 + 地支六冲六合（三合三会）✅
3. 八卦与六十四卦 + 万物类象 ✅
4. 干支历法（年月日时、节气、月建日辰、旬空）← 当前

### 第二阶段 · 六爻（liuyao/，8 节）
1. 金钱卦起卦法（摇卦、排卦、动爻、本卦变卦）
2. 装卦①：纳甲与安世应
3. 装卦②：配六亲与安六神
4. 断卦核心：用神与日辰月建旺衰
5. 动爻、变爻与生克链条（原神 / 忌神 / 仇神）
6. 断吉凶成败 + 空亡、墓库、冲合
7. 断应期 + 分类占法（求财 / 求职 / 感情 / 失物）
8. 实战占验与复盘

### 第三阶段 · 梅花易数（meihua/，6 节）
1. 梅花起卦法（时间、数字、方位、外应）
2. 体用生克断法
3. 万物类象与卦象直读
4. 断应期与细节
5. 分类占法
6. 实战占验

### 第四阶段 · 大六壬（liuren/，10 节）
1. 六壬基础：月将、占时、天地盘
2. 四课
3. 三传（九宗门）
4. 十二天将
5. 神煞
6. 课体格局（九课体）
7. 断法：类神、旺衰
8. 分类占法
9. 应期
10. 实战占验

### 第五阶段 · 奇门遁甲（qimen/，12 节）
1. 奇门基础：九宫八卦、节气定局
2. 排盘①：地盘、天盘
3. 排盘②：八门
4. 排盘③：九星
5. 排盘④：八神
6. 三奇六仪
7. 格局①：吉格
8. 格局②：凶格
9. 断法：用神、主客、旺衰
10. 择方择时
11. 分类占法
12. 实战占验
