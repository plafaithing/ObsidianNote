## 通用基础

### 阴阳
- **阳**：动、热、明、刚、奇数。爻象为 ⚊（实线）。
- **阴**：静、冷、暗、柔、偶数。爻象为 ⚋（断线）。
- **少阳 / 少阴**：阳静 / 阴静，不变。金钱卦中 7 为少阳、8 为少阴。「少」（年轻）则稳定。
- **老阳 / 老阴**：阳极 / 阴极，将变。金钱卦中 9 为老阳、6 为老阴，为动爻。「老」（极点）则物极必反，故动。**动爻 = 老阳 / 老阴，是阴阳的极变状态，不是脱离阴阳的新概念。** 详见 Q&A Q1。
- **阳进阴退**：阳主进（增长），少阳 7 进至老阳 9；阴主退（减损），少阴 8 退至老阴 6。少 / 老由进退定，非由数之大小定——故阴的少老与阳「反着来」。详见 Q&A Q3。
- **大衍揲蓍法**：《周易·系辞》古筮法，以 49 根蓍草三变得一爻。过揲之策除以 4 得 6/7/8/9：36→9 老阳、32→8 少阴、28→7 少阳、24→6 老阴。金钱卦的 6/7/8/9 即源于此。
- **天地之数**：《系辞》1-10。天数（奇）1/3/5/7/9 和 25，地数（偶）2/4/6/8/10 和 30，共 55。
- **生数 / 成数**：河图数理。1-5 为生数（始生），6-10 为成数（成就）。爻象用成数 6/7/8/9（水火木金之成数），10 为土之成数居中央不用。详见 Q&A Q4。

### 五行
- **五行**：金、木、水、火、土，五种能量状态。
- **相生**：木生火，火生土，土生金，金生水，水生木。
- **相克**：木克土，土克水，水克火，火克金，金克木。
- **旺相休囚死**：五行在不同季节的强弱状态（如春季木旺、火相、水休、金囚、土死）。

### 干支
- **天干**：甲乙丙丁戊己庚辛壬癸（10 个）。
- **地支**：子丑寅卯辰巳午未申酉戌亥（12 个）。
- **六十甲子**：天干地支依次配对，60 一循环。
- **地支六冲**：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。
- **地支六合**：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。
- **地支三合**：申子辰合水局、亥卯未合木局、寅午戌合火局、巳酉丑合金局。
- **地支三会**：寅卯辰会木、巳午未会火、申酉戌会金、亥子丑会水。
- **四库 / 四墓**：辰戌丑未四个土支，分别是水火金木的墓库。辰为水库、戌为火库、丑为金库、未为木库（源于三合局墓位：申子辰水局辰为墓，等）。按季节顺序为辰（春末）未（夏末）戌（秋末）丑（冬末）；习惯连称「辰戌丑未」因辰戌冲、丑未冲配对。

### 八卦
- **八卦**：乾兑离震巽坎艮坤。
- **先天八卦**：伏羲所定，讲对待（方位对立）。
- **后天八卦**：文王所定，讲流行（时序流转）。
- **万物类象**：八卦对应自然、人体、方位、季节、人物等类象系统（梅花、六爻、奇门共用）。

### 历法
- **月建**：当月地支，如寅月为正月。断卦判断旺衰的依据。
- **日辰**：当日的干支。断卦判断旺衰、冲合、空亡的依据。
- **节气**：定月建、定奇门局的依据。
- **旬空 / 空亡**：以日柱查旬中空亡的两个地支。六爻、六壬常用。

## 六爻
- **纳甲**：把天干地支配入六爻（乾内甲子、坤内乙未等）。
- **世应**：卦中两个特定爻位，世为自己，应为对方或所测之事。
- **六亲**：父母、兄弟、子孙、妻财、官鬼。配在六爻上代表各类人事关系。
- **六神 / 六兽**：青龙、朱雀、勾陈、螣蛇、白虎、玄武。按日干安于六爻，辅助判断。
- **用神**：所占之事对应的六亲爻。如求财以妻财为用神。
- **原神**：生用神之爻。
- **忌神**：克用神之爻。
- **仇神**：克原神、生忌神之爻。
- **静爻 / 动爻**：不变之爻 / 变化之爻。动爻主导事态变化。
- **变爻 / 变卦**：动爻变化后的爻 / 卦。
- **空亡**：爻落空亡，有事不实、暂不成之象。
- **入墓**：爻入墓库，主困住、收藏。

## 梅花易数
- **体卦 / 用卦**：卦中分体用。动爻所在卦为用，不动卦为体。体为己，用为事。
- **体用生克**：用卦生体卦则吉，克体则凶。
- **互卦**：取卦中二三四爻、三四五爻组成，看事物中间过程。
- **变卦**：动爻变后的卦，看事物结局。
- **外应**：起卦时外界偶发的征兆，作为辅助判断。
- **万物类象**：以八卦类象直读事物（见通用·八卦）。

## 大六壬
- **月将**：当月太阳所在位置对应的地支，为六壬起课依据。
- **占时**：起课的时辰地支。
- **天地盘**：地盘固定（地支方位），天盘随月将加占时转动。
- **四课**：由日干支与天地盘推得的四组关系，断事之始。
- **三传**：初传、中传、末传。事物发展的三个阶段。九宗门定三传。
- **九宗门**：贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、返吟。定三传的九种法则。
- **十二天将 / 贵神**：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后。配于天盘地支。
- **神煞**：各类吉凶神煞（如天乙、驿马、桃花等）。
- **课体**：四课三传的格局名称（元首、重审、始入、知一、涉害等九体）。
- **类神**：所占之事对应的天将或神煞。

## 奇门遁甲
- **九宫**：洛书九宫，奇门排盘的方格框架。
- **八门**：休、生、伤、杜、景、死、惊、开。主人事动向。
- **九星**：天蓬、天任、天冲、天辅、天英、天芮、天柱、天心、天禽。主天时大势。
- **八神**：直符、螣蛇、太阴、六合、白虎、玄武、九地、九天。主神秘助力。
- **三奇六仪**：三奇乙丙丁，六仪戊己庚辛壬癸。排布于九宫。
- **局**：奇门局分阳遁九局、阴遁九局，共 18 局，按节气定。
- **节气定局**：以节气确定用阳遁还是阴遁、第几局（《烟波钓叟歌》口诀）。
- **直符 / 直使**：当值的星与门，为断事枢纽。
- **主客**：奇门断事分主客，动静先后决定吉凶。
- **格局**：吉格（如青龙返首、飞鸟跌穴）、凶格（如青龙逃走、白虎猖狂）。由星门奇仪组合判定。
